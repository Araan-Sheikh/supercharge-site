# Supercharge CLI

Supercharge is a free Rust coding agent you run on your machine. You pay the model provider you connect in `/setup`. There is no Supercharge subscription and no credit balance.

The agent calls itself Supercharge AI, built by R3AP3R Editz. It is a terminal UI over your repo: it reads files, runs shell commands, edits code, and can call tools you add.

## Start here

1. [Install](/docs/install) the binary.
2. Run `supercharge` in a project.
3. Run `/setup` and save a provider. The listed providers, key versus browser sign-in, and the three API formats are on [Provider setup](/docs/setup).
4. Type a task and press Enter. The agent asks before it runs a shell command or edits a file.
5. Press Shift+Tab to move among Agent, Plan, Ask, any custom agent you created, Always-Approve, and Auto-Review. How those differ is on [Permissions](/docs/permissions) and [Custom agents](/docs/agents).

A normal turn can read the repo, edit files, and run commands. `/plan` makes it write the plan first. Ask only answers. `/queue` shows prompts waiting behind the current turn. `/tasks` shows background work. `/resume` comes back to a saved session. `/model` and `/effort` change the model for later turns. `/compact` shrinks history when the window fills up. The full list is on [Slash commands](/docs/slash).

## Where everything lives

| Path | What it is |
| --- | --- |
| `~/.local/bin/supercharge` | Usual install location. `sc` is a second name for the same binary when the installer created that link. |
| `~/.supercharge/config.toml` | Provider, models, UI, and feature settings. |
| `~/.supercharge/sessions/` | Saved conversations. |
| `~/.supercharge/memories/` | Curated notes: `USER.md` and `MEMORY.md`. |
| `~/.supercharge/agents/` | Custom agents you created for every project. See [Custom agents](/docs/agents). |
| `~/.supercharge/docs/user-guide/` | Built-in guides copied on launch. `/docs` opens them inside the TUI. |

`SUPERCHARGE_HOME` moves that whole directory. `SUPERCHARGE_BIN_DIR` moves only the install location.
