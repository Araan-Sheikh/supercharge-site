# Permissions

By default the agent asks before it runs a shell command or edits a file.

Work mode and permission mode are separate. Shift+Tab changes both, one stop at a time. Details of custom agents are on [Custom agents](/docs/agents).

| Work mode | What the model does |
| --- | --- |
| Agent | Reads, edits, and runs tools. This is the normal chat. |
| Plan | Writes a plan first. `/plan [text]` enters it and can start the turn with that text. `/view-plan` shows the saved plan. |
| Ask | Read-only. It answers and does not write files, including a new agent file. |

| Permission mode | What happens before a tool runs |
| --- | --- |
| Ask | You approve each shell command and edit. |
| Auto-Review (`/auto`) | A classifier approves tools it treats as safe. Dangerous ones can still ask. |
| Always-Approve (`/always-approve`, Ctrl+O, `--yolo`) | Tool prompts are skipped. Deny rules and hooks still apply. |

Turning on the permission mode you are already in switches back to ask. Turning one permission mode on while another is active switches to the new one. Always-Approve wins over Auto-Review when both would be set. Always-Approve and Auto-Review also return the work mode to Agent.

## Modes

| How | Effect |
| --- | --- |
| Default | Ask each time. |
| `/always-approve`, Ctrl+O, `--yolo`, `--permission-mode bypassPermissions` | Skip approval prompts. |
| `/auto` | Auto-Review. A classifier approves tools it treats as safe. Dangerous ones can still ask. |
| Shift+Tab | Cycle Agent, Plan, Ask, your custom agents, Always-Approve, then Auto-Review. |
| `/plan` | Plan before coding. `/view-plan` shows the saved plan. |

Always-approve is the mode to use when nobody is at the keyboard (`supercharge agent serve`, a daemon, CI). Deny rules and hooks still apply.

## Rules

`--allow` and `--deny` are repeatable and work in the UI and in headless mode. They gate a tool. They do not remove it. `--disallowed-tools` removes the tool from a headless run.

```bash
supercharge --deny 'Bash(rm *)' --allow 'Bash(git *)'
supercharge -p "lint the repo" --deny 'Edit(**)'
```

| Prefix | Matches |
| --- | --- |
| `Bash(...)` | Shell text. `*` matches any characters, including spaces. `Bash(git:*)` is a prefix match. A bare `Bash` matches every command. |
| `Edit(...)`, `Write(...)`, `Read(...)`, `Grep(...)` | Paths. `*` is one level. `**` is recursive. |
| `WebFetch(...)` | URL glob, or `domain:host`. |
| `MCPTool(...)` | An MCP tool call. |

Project memory of "always allow this command" is on by default (`[ui] remember_tool_approvals = true`). The first approval prompt's preselected row is `[ui] default_selected_permission`.

Plan mode and permission prompts are per session unless you pass the flags at launch or save the UI defaults.
